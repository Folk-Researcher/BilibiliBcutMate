## 目标
- 提供可直接触发并验证 `create_draft` 的方式（CLI 与测试）。
- 明确验证标准：目录、`.bjson` 文件、`draftInfo.json` 元信息、索引结果。

## 现状定位
- 创建方法：`bcut_drafts.py:155` 的 `create_draft(...)`。
- 依赖方法：`bcut_models.py:241` 的 `create_empty_project(...)` 与 `bcut_models.py:232` 的 `save_bcut_project(...)`。
- 草稿索引：`bcut_drafts.py:105` 的 `build_drafts_index(...)`；已有 CLI 入口 `summarize-drafts`。

## 实施方案
1. 增加 CLI 子命令 `create-draft`
   - 入口：`main.py` 中新增 `create-draft`，参数包含 `--base-dir`、`--name`、分辨率、帧率、音频参数、`--draft-version`。
   - 行为：调用 `create_draft`，输出 `{draft_id, folder, bjson}`。
2. 编写最小化测试用例（pytest）
   - 使用临时目录作为 `base_dir`，调用 `create_draft`。
   - 断言：
     - 返回的 `folder` 与 `bjson` 均存在；`bjson` 文件非空。
     - `draftInfo.json` 中存在对应 `id` 与 `name`；`modifyTime` 合理。
     - `build_drafts_index(base_dir)` 返回包含该草稿且 `bjson_files` 命中。
3. 文档化本地手动验证步骤（无需改代码即可试用）
   - Python 交互调用 `create_draft("Bcut Drafts", "测试草稿")`。
   - 检查 `Bcut Drafts` 下新增目录与 `draftInfo.json` 更新；可调用 `build_drafts_index` 做二次确认。

## 验证标准
- 生成目录与 `.bjson` 文件；文件名包含时间与 GUID。
- `draftInfo.json` 新增或更新条目，`id` 大写 UUID，`name` 为指定名称。
- `summarize-drafts` 与 `build_drafts_index` 能正确统计到新草稿。
