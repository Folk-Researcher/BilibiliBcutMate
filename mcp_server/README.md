# MCP Server for Bcut

This project is a simple MCP (Model Context Protocol) server for interacting with Bcut project files.

## How to Run

1.  Install dependencies:
    ```bash
    pip install -r requirements.txt
    ```

2.  Run the server:
    ```bash
    python app.py
    ```

3.  The server will be running at `http://127.0.0.1:5001`.
